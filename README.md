# CSD-Nano

Custom SimHub dashboards and LED profiles for the **Conspit CSD Nano 2.99"** display (800×268). Free for the community.

## Compatibility

| | |
|---|---|
| **Supported** | Conspit CSD Nano 2.99" (800×268), on any wheelbase |
| **Mounting** | Magnetic pogo-pin mount on Conspit ARES / ARES Platinum, or USB-C on other setups |
| **Not supported** | Conspit 310 APEX and 300GT wheel screens — same size, but their screens run Conspit Link's built-in dashes, not custom SimHub dashes |
| **Requires** | SimHub on a Windows PC |

## Contents

- `Dashes/` — SimHub dash files (`.simhubdash`)
- `LED Profiles/` — SimHub LED profiles

## Install

1. Download the `.simhubdash` file you want from `Dashes/`.
2. Double-click it (or import it in SimHub → Dash Studio).
3. Pick it for the CSD Nano screen in Dash Studio.
